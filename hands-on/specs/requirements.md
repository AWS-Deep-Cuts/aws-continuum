# 要件: 取引先ポータル

## 背景

これまで、取引先は注文の CSV をメールで店に送り、店の担当者が `partner_report.py` で報告を作って、メールで送り返していました。取引先の数が増え、担当者の作業が追いつかなくなっています。

## 要件

1. 取引先は、注文の CSV を Web からアップロードできる。
2. 取引先は、これまで店の担当者が作ってメールで送っていた報告を、自分でダウンロードできる。
3. 店は、取引先ごとに API キーを発行し、その API キーで取引先を識別する。
4. 報告の中身は、今の `partner_report.py` の出力と同じにする。

## 対象外

- 取引先の登録と API キーの発行の画面は、今回は作らない。店の担当者が `data/partners.csv` を直接編集する。
- 支払いと配送の機能は、今回は作らない。

## 利用者

| 利用者 | 行うこと |
| --- | --- |
| 取引先 | 注文の CSV のアップロード、報告のダウンロード |
| 店の担当者 | 取引先の登録、API キーの発行 |
